# Frequently asked questions

## Is this institutional-quality buy-side work?
It is designed around buy-side research-process requirements: instrument-specific questions, financial transmission, evidence lineage, reproducible arithmetic, counterarguments, catalysts, downside, material-gap handling and human review. Version 0.1.0 is a tested prototype, not an independently certified or production-audited investment system.

## What does a tradable workflow mean?
The workflow links research to a specific security or investable private contract and checks valuation, liquidity, legal access, mandate fit, portfolio risk and downside before a candidate classification. A private project is not a liquid security. A sustainability programme or nature-credit concept may have no investment route. No trading API, orders or execution authority exist in this package.

## What makes the workflow traceable and auditable?
Evidence IDs, locators, dated source records, typed claims, unit-aware calculations, frozen instructions, revision history, downstream invalidation and human-review attestations are retained in local run files. They are reviewable, not tamper-proof or independently verified. Source truth, semantic support and identity authentication remain outside the engine.

## Does the agent run without an LLM API key?
Its CLI, calculations, validation and synthetic demos run locally without a key or network access. Actual research requires a host AI or human with separately authorized source tools. The package does not contain an embedded LLM or automatic web/document retrieval. Text-only use of the prompts does not enforce Python gates.

## Are the example reports live investment recommendations?
No. Synthetic examples are fictional. The historical primary-source study replays a limited announcement extraction and intentionally stops on material gaps. No present-day attractiveness, impact verification, expected return or execution recommendation is established.

## Which AI platform is supported?
The instructions are portable text with a root SKILL.md and bounded child skills. A filesystem-enabled host that can read the package and run Python can follow the workflow. Specific products, automatic activation, installation and provider integrations have not been certified or integration-tested.

## Can it prove impact or regulatory compliance?
No. It structures evidence and highlights what has to be verified. Causality, ecological outcomes, legal enforceability, mandate applicability and regulatory compliance require the relevant evidence and qualified review. Voluntary frameworks and future reforms must not be silently treated as current law.

## Will GEO/SGO guarantee discovery?
No. Clear public documentation, descriptive metadata, trustworthy citations and inspectable examples support discoverability. Search engines determine crawling, indexing and inclusion. Optional navigation and structured metadata are not guaranteed ranking mechanisms.
